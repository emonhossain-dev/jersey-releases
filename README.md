# Jersey Auto

Adobe Illustrator-এর জন্য জার্সি প্রোডাকশন অটোমেশন। প্লেয়ারের লিস্ট দিন, অ্যাপ নিজেই নাম, নম্বর ও সাইজ বসিয়ে সাইজ চার্ট অনুযায়ী স্কেল করে, 63 ইঞ্চি চওড়া শিটে সাজিয়ে AI / TIF / PDF / EPS এক্সপোর্ট করে এবং ZIP বানিয়ে দেয়।

## ডাউনলোড

**[➡ সর্বশেষ ভার্সন ডাউনলোড করুন](../../releases/latest)**

Release পেজের **Assets** অংশ থেকে `JerseyAuto-Setup-x.x.x.exe` ফাইলটি নামান।

## প্রয়োজনীয় জিনিস

- Windows 10 / 11 (64-bit)
- Adobe Illustrator ইনস্টল করা (অ্যাপ চালানোর আগে অন্তত একবার খুলে বন্ধ করে নিন)
- ইন্টারনেট সংযোগ (লগইন ও ক্রেডিটের জন্য)
- আমাদের ওয়েবসাইটে একটি অ্যাকাউন্ট ও লাইসেন্স / ক্রেডিট

## ইনস্টল করার নিয়ম

1. উপরের লিংক থেকে `.exe` ফাইল নামান।
2. ফাইলে ডাবল ক্লিক করুন।
3. Windows নীল রঙের **"Windows protected your PC"** সতর্কতা দেখালে **More info** চাপুন, তারপর **Run anyway** চাপুন। (অ্যাপটি এখনো Microsoft-এর publisher সার্টিফিকেট ছাড়া বিতরণ হচ্ছে, তাই এই সতর্কতা আসে।)
4. ইনস্টলারের ধাপগুলো শেষ করুন। ডেস্কটপে **Jersey Auto** শর্টকাট তৈরি হবে।

## প্রথমবার ব্যবহার

1. **লগইন:** ওয়েবসাইটের ইমেইল ও পাসওয়ার্ড দিয়ে ঢুকুন। অ্যাকাউন্ট না থাকলে **Register on the website** চাপুন।
2. **License:** আপনার লাইসেন্স কী অ্যাক্টিভেট করুন। প্রতি জার্সিতে ১টি ক্রেডিট কাটে, ব্যর্থ জার্সির ক্রেডিট ফেরত আসে।
3. **টেমপ্লেট:** Illustrator-এ আপনার টেমপ্লেট (.ai) খুলে সেভ করুন, তারপর অ্যাপে **Use document open in Illustrator** চাপুন।
4. **Layer mapping:** Illustrator-এ অংশটি (FRONT, BACK, হাতা, NAME, NUMBER ইত্যাদি) সিলেক্ট করে অ্যাপে সেই নামের **Assign** চাপুন। NAME ও NUMBER অবশ্যই লাইভ টেক্সট হতে হবে (আউটলাইন নয়)।
5. **Size chart:** নিজের মাপ বসান এবং যে সাইজে ডিজাইন আঁকা সেটা **Base size** দিন।
6. লিস্ট আনুন (Paste import বা Open JSON), ফরম্যাট ও আউটপুট ফোল্ডার বেছে **START** চাপুন।

আউটপুট পাবেন `JOB_তারিখ_সময়` ফোল্ডারে এবং পাশে একটি `.zip` ফাইলে।

## আপডেট

নতুন ভার্সন এলে অ্যাপ নিজে ডাউনলোড করে জানাবে। উপরের নীল বারে **Restart & update** চাপলেই আপডেট হয়ে যাবে। জব চলার সময় আপডেট ইনস্টল হয় না। হাতে চেক করতে উপরের **Updates** বাটন চাপুন।

## সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| `Library not registered` / `TYPE_E_LIBNOTREGISTERED` | Illustrator-কে একবার **Run as administrator** দিয়ে খুলে বন্ধ করুন, অথবা Creative Cloud থেকে Illustrator **Repair** করুন। |
| `Illustrator is not installed (or not registered)` | Illustrator ইনস্টল আছে কিনা দেখুন, একবার খুলে বন্ধ করে আবার চেষ্টা করুন। |
| `Illustrator is busy` | Illustrator-এ কোনো ডায়ালগ খোলা থাকলে বন্ধ করে আবার চেষ্টা করুন। |
| `The document in Illustrator is not saved yet` | টেমপ্লেটটি Ctrl+S দিয়ে সেভ করুন, তারপর আবার Assign করুন। |
| `Size ... is not in the size chart` | **Size chart...** এ ওই সাইজ যোগ করুন বা লিস্টের সাইজ ঠিক করুন। |
| অ্যাপ ও Illustrator একসাথে কাজ করছে না | দুটোই একই ভাবে চালান: দুটোই সাধারণ মোডে, অথবা দুটোই "Run as administrator"-এ। |

সমস্যার সময় অ্যাপের নিচের লগের লেখাগুলো কপি করে আমাদের পাঠান।
